## 我怎么工作

<p align="center">
  <img src="assets/workflow.svg" width="880" alt="工作流：研究 → 结构化 → 原型 → 验证 → 自动化，产出回流为可复用资产">
</p>

- **先定规则，再谈实现** — 模糊需求先收敛成输入、字段、规则、输出与复核责任，然后才动手
- **证据可追溯** — 结论要能回溯到来源，不确定性要显式标注，不藏在结论里
- **判断留给人，执行交给 Agent** — 高频、重复、规则明确的环节先自动化；判断类环节保留人工复核
- **一次性工作变成可复用结构** — 把做过的事沉淀为规则、脚本、SOP 或 Skill
- **发布前必须验证** — 自动化检查、浏览器实测、明确的评审关卡
